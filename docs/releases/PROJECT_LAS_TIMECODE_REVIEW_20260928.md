# 九九项目：从 LAS 时间码定位原片

日期：2026-09-28。目标是缩短“机器观察 → 核实原片”的操作距离，不改变项目案例核看的签署门槛。

## 输入、输出与协作

- 输入：当前项目、已接受视频、项目专属 LAS 完成正文中的结构化时间段，以及该项目的私有视频预览权限。时间段来自供应商，仅是待核线索。
- 在视频库的“本项目整片音画分析”展开任务，点击事件或动作细节的起始时间码；页面仅调用既有的项目私有视频预览接口，加载五分钟链接并将播放器定位到该时间。不会自动播放、自动保存 Case、创建 LAS 任务或改变日账。
- 定位请求同时绑定项目和视频；切换项目或视频后不复用原请求。时间码超出原片时提示核对，不把它标为有效核看。
- 研究员仍须亲自连续核对必要的画面和原声，在“本项目案例核看”中写事实、缺口、反证及适用边界；机器时间线不能自动升级为 `complete` 或解锁“采用”行动卡。

- 本地 Raw App lint/build、LAS 与项目预览组件定向测试通过。
- 本地 Chrome 合成 2 秒视频交互：点击 `0:01` 后播放器定位且保持暂停；点击 `0:09` 提示超长；切换项目后旧项目的定位请求不再加载视频。该合成测试不等于测试服真实媒体可播放。
