# 项目视频对照的账号关联（045）

状态（2026-09-28）：本地实现、GitHub CI、测试服单应用发布和真实页面回读通过；不等于原帖账号归属或九九内容效果已经验收。

## 业务输入与输出

- 输入：同一项目已纳入的两条公开视频，以及采集库中各视频关联的规范 `source_account` 记录。账号昵称只用于展示，不再用于判断是否同一账号。
- 输出：项目视频库为每条有关联账号的视频返回 `project_account_ref`。它只在同一项目内稳定，跨项目不同；没有账号关联时返回 `null`。双视频对照用该标识区分“同一规范账号记录”“不同规范账号记录”和“无法判断”。
- 解释边界：同一规范记录不是平台官方归属认证；可能存在上游错误关联或同一真实账号的重复规范记录。仍需打开原帖核对作者，不能由同账号及播放差异推断追更、分发原因或目标年龄效果。

## 接口、权限与协作

`get_video_library` 的项目列表和详情新增 `project_account_ref`，由项目 UUID 与全局账号 UUID 生成项目域内不可逆摘要。项目接口继续把全局 `account_id` 保持为 `null`，不返回其他项目的账号关系、评分或来源历史。全局管理员列表保留原 `account_id`，新增字段为 `null`。不改数据库、不调用外部供应商、不增加费用。

项目成员可以在“视频库 → 同屏对照证据”判断两条视频在采集库中是否关联同一账号。内容研究员仍须核对原帖及声画，项目负责人只在证据足够时把观察写入项目 Case；行动复盘和我方发布门槛不因此放宽。

- 本机项目/全局视频库回归：`12 passed`；前端账号比较规则测试通过；Windmill Raw App 的 39 个后端 runnable 校验及 bundle 构建通过。
