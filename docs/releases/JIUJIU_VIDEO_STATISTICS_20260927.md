# 九九项目公开播放量核验入口

日期：2026-09-27。范围：测试服“九九 IP 号”项目的已接受公开视频；不改生产环境，不自动发起付费调用。TikHub 的[抖音 App V3 视频统计接口](https://docs.tikhub.io/186826221e0)用于单次核验最多 2 个精确视频 ID 的点赞、下载、播放和分享统计；详情接口返回的 0 播放仍保留为原始快照，不再把它直接当作真实播放量。

## 输入、输出与边界

- 输入：当前 Windmill 登录用户、项目 ID、1–2 个精确抖音视频 ID；只允许 active 项目的 Owner/Admin 核验本项目 `accepted` 视频。预览只查库；执行还需明确确认，运行期间在 HTTP 前和写快照前再次核验项目权限。脚本只从 Windmill Secret 读取 TikHub Key。
- 接口：`douyin.app.video_statistics`，单次最多 2 个 ID；必须完整回显请求 ID、每个 ID 有非负播放数，否则不提升为业务指标。原始响应和调用记录进入 Provider 存储，指标以新来源快照追加，不改视频/账号主数据。原有合并视图按字段取最新可靠来源，缺失字段保留其他来源。
- 输出：两个视频的播放量、快照数、新发/缓存调用数、项目运行 ID、基础价格估算；不给页面返回原始 Provider 响应或 Key。项目日账将此任务列为“播放核验”，估算与供应商实扣仍分开。
- 业务验收：真实统计值必须在视频详情、指标时间线、账号页与项目日账回读；要和已保存的旧详情 0 值并列核查。即使取到播放量，也不足以证明内容方案优劣，还需完整审片、同类分层比较及目标受众验证。
