状态：2026-09-26 测试服真实采集与页面回读；**不是九九内容制作方向验收**。

## 业务输入与执行

目标是检验原创 AI 角色内容能否提供比旧景区 NPC 样本更贴近九九纯 AI 角色号的研究依据。项目研究员先核对公开视频，再将两条 HandsMini 视频纳入“九九 IP 号”项目。第二条《奥术之贼｜01》只完成部分画面核看，已在研究台保存事实、反证和证据缺口；未完整看完或核听声音，不能升级为“完整可分析”。

评论通过测试 Windmill 手动 Flow `f/content_research/flows/manual_comment_collection` 调用 TikHub `fetch_video_comments`，每页请求 20 条、每次最多 10 页；每轮保存游标，跨页与跨轮去重，并重建 L2 评论特征。一次超出 `max_pages` 上限的输入在调用前被拒绝，外部调用数为零。没有自动周期采集、ASR 或 L3 调用。

## 页面、权限与验收

项目视频库现对**已接受**视频显示最新评论特征的五项有界汇总：去重样本、观测数、可分析文本、含问号文本、重复文本；不输出特征快照的元数据或指纹。项目候选与撤回接受后的 `shortlisted` 状态均不显示此汇总，跨项目候选也不继承。侧栏视觉布局经 Chrome 实际回读，五项按 3＋2 排列，旁边仍保留样本偏差说明和项目原始依据入口。

本机 Python 编译、前端 esbuild 及独立临时 PostgreSQL 定向测试通过（11 项），包括项目 A/B 隔离、已接受转回 `shortlisted` 后隐藏和字段白名单。PR [#155](https://github.com/lig9904/douyin-research-platform/pull/155) 包含源码与测试；测试服只向 `test-research` 发布研究台单个 Raw App，官方 CLI 返回 `Raw app pushed`、退出码 0。刷新 [测试研究台](https://dy.yudao.cc:6443/public/test-research/5489eccf05928fcaac13d8d75ae6b9c6) 后，《奥术之贼｜01》详情实际显示 410 / 527 / 401 / 58 / 6，与最新 L2 数据库回读一致。发布令牌仅含 `apps:write`、`raw_apps:write`、`users:read`，一小时有效；值未写入仓库或本文，终端变量已清除，沿用用户选择到期失效。

## 当前可支持的判断与尚缺证据

这两条提供了纯 AI 角色内容评论采集、去重、特征重建及项目页面查看的真实闭环。公开评论已出现角色、能力规则、后续更新等讨论线索；但这是非随机样本，第二条仅部分审片，且播放量为零与正向互动冲突，不能计算互动/播放比。**目前只能提出待验证的表达假设，不能宣称这种叙事会让九九目标客群记住角色或追更。**

业务验收下一步需要：至少一条完整视听核看且权利边界清楚的正例、一条可比反例；把角色行动、观众可见后果、声音/节奏与评论证据逐案绑定；再由内容负责人选择可拍实验。正式九九账号尚未发布，因此自有观看、关注与复盘指标仍不可验收。
