# 项目双视频对照（044）

## 业务范围

项目成员在“视频库”对同项目、已纳入的两条视频勾选“对照”，同屏查看合并指标、采集时间和项目专属 LAS 分段机器观察。项目库展示该项目全部未归档视频，不再误标为近 30 天或近一年；全局库仍保持近 30 天默认值。此页面只读，不产生新的采集、分析或供应商费用。

## 输入、输出与边界

- 输入：当前项目 ID 和两条已接受视频 ID。每列调用现有项目权限接口 `get_video_library` 获取该视频详情，调用 `project_las_video_review(status)` 获取同项目 LAS 记录。Windmill 后端桥接会把省略的可选参数传为空值，因此详情请求显式带齐安全的筛选默认值；任一视频不再被接受或无权读取时整组拒绝展示。
- 输出：播放、点赞、评论、分享及合并字段计算的互动/播放参考值；字段采集时间；已完成且绑定对象版本的真实 LAS 机器观察与分段时间码。历史回填、未完成、未绑定对象版本或无正文的任务不参与对照。
- 保留不确定性：分享来源冲突、播放零值与其他正数冲突时显示“待核”；账号名称相同但项目接口未提供账号 ID 时不声称同一账号；预估费用不称“实扣”；机器观察不称人工案例，不据播放差异推出内容因果或追更效果。
- 协作：项目 Owner/Admin 可在视频详情继续核对整片声画并建立项目 Case；普通项目成员仅按现有 ACL 阅读。行动复盘仍需人工核看和我方发布后真实表现。
