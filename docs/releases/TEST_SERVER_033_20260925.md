- C 的项目列表为空、`legacy_admin=false`；直接请求 A 和 B 均返回 `RESEARCH_PROJECT_ACCESS_DENIED`。这验证了发布后的服务器端读隔离，不以页面隐藏或管理员切换项目代替授权检查。
