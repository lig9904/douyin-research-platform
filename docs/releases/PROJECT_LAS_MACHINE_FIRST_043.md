# 043：项目视频机器先分析授权

状态（2026-09-28）：043 已在测试服完成迁移、隔离恢复、单应用与 Worker 发布；隔离项目的一条公开视频完成真实授权、单次 Submit、原任务 Poll 和项目页面回读。计划任务保持禁用。这是技术链路验收，不是内容方向验收。

## 输入、输出与接口

- 输入为项目内已接受的完整视频、可验证的对象版本和字节指纹，以及项目负责人明确保存的云端机器分析授权。保存授权与启动付费任务是两个动作；授权不声明任何人已完整人工核看。
- 独立授权表 `project_las_video_authorization` 不覆盖人工审核表。Worker 在发出 HTTP 前复核项目、授权、资产和版本；只 Submit 一次，结果不明时保留原任务等待回查，不自动重提。
- 页面输出标明供应商机器观察，不自动写为人工 Case、行动建议或正式创意。费用凭证与任务绑定；没有可核对的供应商分笔时保持“待对账”。

## 协作与验收

测试服发布前后双库备份与隔离恢复通过，运行库未被覆盖；应用与三条 Worker 脚本按固定版本回读，计划任务仍禁用。负责人通过研究台保存授权后，一条持久任务经单次 Submit 与原任务 Poll 到完成，机器摘要与分段在项目页面可见。一次错误任务标识仅在数据库预检阶段失败，没有发出 HTTP；失败作业保留审计。

另有已接受媒体完成全字节巡检、独立对象备份、条件版本提升和新旧版本可读性核查，再分别用真实云端机器分析回读。精确媒体、版本、任务、剧情观察和比较数据保存在受控记录；公开仓库只保留上述机制与技术结果。机器观察尚缺人工连续核看和正式素材权利确认，不能据此批准内容方向。测试服社区版不执行企业并发限制，相关写入操作须保持串行与数据库幂等保护。
