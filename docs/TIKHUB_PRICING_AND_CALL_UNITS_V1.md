## 调用量折算规则

### 低粉爆款榜

- 一页请求计 1 次，`page_size` 只影响返回条数，不按条数另计费。
- 黄金采集固定只取第 1 页，最多请求 5 条，最多产生 1 次该接口调用。
- 翻页会按页数增加请求数；缓存命中时不产生新的 TikHub 请求，也不产生实际费用。

### 批量视频详情

- 先按视频 ID 去重，再按每批最多 50 个 ID 切分。
- 当前强制50批路由在全部批次未命中缓存时，对 `N` 个去重 ID 调用 `ceil(N / 50)` 次。
- 基础费用公式：`ceil(N / 50) × 0.050 USD`；命中部分缓存应扣除对应批次，支持折扣的请求另算。
  这是当前实现，不是最佳调用方式；小批应评估单条/10批，纯指标刷新评估统计接口。
- 本次 `N=3`，所以为 `ceil(3/50)=1` 次，费用 `$0.050`。

### 缓存与失败

- 缓存命中记录 `actual_cost=0`，不占用新的供应商请求次数。
- 当前黄金采集和手动评论入口显式不自动重试；通用Transport默认仍支持重试，不能概括成全部Provider零重试。
- 日累计按“未缓存外部请求”预占；成功时通常是单价快照估算，并非自动读到账单。
  供应商实际费用需要对账回填；当前两次调用已完成该对账。
