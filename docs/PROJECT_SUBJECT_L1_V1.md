## 输入、输出与协作

| 模块 | 输入 | 输出或接口 | 协作与验收 |
|---|---|---|---|
| 主体相关性 | 项目、活跃主体、别名/地理上下文/排除词、项目纳入的公开视频；研究员可人工纠错 | `project_video_subject_relevance` 的 relevant/pending/irrelevant 和审计 | 规则词变动使旧规则结论待重新评估；人工结论保留。无关同名视频不得进入该主体评分 |
| 项目 L1 | 同一采集 run 中、当前 relevant 且项目纳入状态可用的视频，以及可获得的公开指标 | `project_video_subject_score` 按项目/视频/主体/run 留一份不可变、可追溯的确定性分数；运行摘要返回已持久化值 | 不写全局 `video_score` 或 `source_video` 监测状态；缺数据标低置信度。分数仅用于当前候选相对排序，不代表内容质量、粉丝增长或经营效果预测 |
| 付费详情 | 预检后的确切视频 ID 批次 | 缓存未命中时，在预算预留和单次 HTTP 前按项目/主体/视频当前状态复验，持锁至请求结束 | 任一 ID 被改成无关、拒绝纳入、不可用或项目停用，整批不发请求、不预留预算；缓存命中不产生外部付费调用 |
| 付费发现 | 当前项目及主体状态、用户限定的来源/时间窗 | 缓存未命中时持项目、组织、主体共享锁覆盖预算预留与单次 HTTP | 暂停先提交则拒绝调用；已授权调用完成后才允许并发暂停落库。费用按现有 Provider 调用账本记录，不由 L1 评分本身产生 |
| 研究台 | 当前项目、主体、最近一批候选和成员权限 | 展示最近批次项目分数、数据置信度、原始依据入口；不跨批次混排 | 只让项目授权成员查看；旧评分若晚于相关性变更失效，不作为当前排序依据 |

## 未完成与上线门槛
