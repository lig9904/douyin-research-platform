## 失败原因与修复

1. 先前单 Worker 导致父任务占槽等待子任务。测试服现使用两个独立普通 Worker。
2. `parent_job` 并未传递 App viewer 身份，子任务在读取 Key 前失败。
   黄金采集现直接在已认证 App 后端执行，复用原有 `run_live`。
3. 该版本无 app-script ID 的执行路径会忽略 inline lock；旧式 `#requirements:`
   声明未使运行时安装依赖。现使用 PEP 723 声明版本与依赖。

手动 App 操作检查登录用户权限；采集核心只需要服务器 API Key 和任务来源，
不依赖浏览器登录。定时采集尚未在本次验收中启用或验收。
专用反代继续负责公网入口；测试机无需新增 Nginx。
