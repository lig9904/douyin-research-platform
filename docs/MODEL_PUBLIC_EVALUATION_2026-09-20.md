## 业务决策

| 业务 | 当前选择／候选 | 输入、输出与验收 |
| --- | --- | --- |
| L3 案例研究 | 保留现有火山链路，不因网上排名切换 | 同一版本证据包 → 可校验的结构化结论；检查事实引用、无证据推断、字段完整率、延迟和实际 token 费用 |
| 清晰普通话转写 | Paraformer V2 可作低成本候选，尚未实测 | 同一已授权音频 → 带时间戳文本；人工校对专名、漏字和时间戳，不能只比较返回成功率 |
| 强配乐、口音、多人声音 | SeedASR 2.0 与 Qwen Audio 3.0 文件转写保留为后续候选 | 相同音频、声道和参数；比较可用转写成本、漏转写、说话人分离与人工修订成本 |
| 多模态证据 | 保留 Seed2.0 Lite 方向，未证明优于同价候选 | 带来源及时间位置的图像／文本证据 → 结论；另外计算视觉输入费用，不套纯文本单价 |

这是研究后的暂定安排，不代表新模型已接入、已调用或已通过验收。

## 公开证据能说明什么

- [字节 Seed2 官方资料](https://seed.bytedance.com/zh/seed2/)能说明供应商宣称的能力与自测结果，
  不能替代本项目的中文短视频证据包评测。
- [阿里 ASR 官方模型说明](https://help.aliyun.com/zh/model-studio/asr-model)用于核对时间戳、
  文件输入及模型差异；普通同步 ASR 与 filetrans 不混为同一种服务。
- [Paraformer-v2 论文](https://arxiv.org/abs/2409.17746)讨论抗噪声识别改进。
  论文结果不等于当前商业 API 的同权重、同参数或同数据集实测结论。
- [阿里结构化输出说明](https://help.aliyun.com/zh/model-studio/qwen-structured-output)区分
  JSON Object 与 JSON Schema。合法 JSON 不代表项目字段契约一定满足，任何供应商结果仍须本地校验。
- [Artificial Analysis 的 Qwen3.8 Flash Next 页面](https://artificialanalysis.ai/models/qwen3-8-flash-next)
  是另一模型版本，不能将其分数套给 `qwen-flash`。后者已按用户要求排除测试。

本次定向检索没有取得覆盖上述精确服务版本、同一中文研究任务和同一数据集的独立对比。
因此不宣称某个候选“已证实最好”，也不为补排行榜而逐个调用所有模型。
