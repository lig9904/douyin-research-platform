状态：2026-09-26 测试服事实与业务判断，**不是制作方向验收**。本记录接续[立项前研究稿](JIUJIU_PREPROJECT_RESEARCH_2026-09-26.md)；旧稿中“尚未建项目”是当时的历史状态，不能作为当前状态使用。

## 目标与已确认输入

- 业务目标是长期运营面向 18–35 岁的“九九 IP 号”，研究角色认知、故事/互动和后续回访意愿；不能把景区门票或一条视频的点赞数当作唯一目标。[试点契约](JIUJIU_IP_ACCOUNT_PILOT.md)仍适用。
- 测试服现有独立的“渔岛 / 九九 IP 号”项目，首位 Owner 是现有管理员身份。项目与验收 A/B 隔离；创建项目不等于已有九九号、自有发布或业务效果。
- 用户确认“渔岛—螭吻九九”和“龙太子九九”均为官方运营的**职人号**，同时明确：这两个号当前发布的内容形式与未来九九 IP 号不同，**不具有本次制作方向的参考意义**。账号官方归属与内容可比性是两个不同判断；不得从前者推导后者。
- 已讨论的候选方向是“角色被认出、角色性格/连续故事、真实场景互动”三类**待证伪假设**，不是已批准的人设或内容栏目。当前权威设定、可拍场景、角色/演员/音乐/游客肖像权及正式账号信息仍须用现期资料核准；不能由模型编造。

## 当前决策与接口

1. **采集 → 候选：**项目研究任务可以自动发现、去重、留原始依据与费用记录；输出默认是候选，不自动“接受”。本轮两个官方职人号作品保留候选审计，不作为下一步选题对标。
2. **候选 → 可比证据：**研究员先完整看实际视频，记录角色在镜头中做了什么、面向谁、观众参与方式、发布条件、可借鉴机制与不可比之处；项目 Owner/管理员再经现有“纳入已有视频”入口确认。仅凭标题、账号官方身份或互动数不得勾选“已核对实际内容”。
3. **可比证据 → 深研：**只有 `accepted` 视频可进入项目私有音频审核；音频需要逐条试听并确认云端转写，L3 还要核对准确待发送正文。未获这些审核不调用付费模型，也不复用其他项目或全局审核。
4. **深研 → 选题：**对贴近目标的正例和反例至少形成两种可否证表达假设，引用具体来源、权威设定版本、可拍权利和主指标。内容负责人决定采用、观察或排除；L3 只给有限证据下的假设。
5. **选题 → 复盘：**未来正式账号发布后，锁定脚本/素材版本、作品 ID、观察窗和自有后台的非个人汇总，复盘“是否认出角色、是否愿看下一集”及可获得的关注/到场信号；没有真实发布和可靠数据，状态停在“待验证”。

下一轮公开案例筛选须围绕**景区角色 IP/演艺角色面向 18–35 岁的可持续表达**，而不是搜索所有含“九九”、所有机甲或官方职人号。优先找角色身份可辨、镜头/叙事可复核、受众和场景接近且有不同表现的案例；跨景区和亲子案例只能作有边界的机制参照或反例。任何案例在完整审片、可比性及权利核查之前都不得被写成“可照搬”或“已证明有效”。

下一轮可优先核对[中国旅游报对夔牛天街“雷泽君”的现场报道](https://www.ctnews.com.cn/paper/content/202507/15/content_104271.html)：它同属本土神兽、大型机械实体和景区场景，报道还提及“螭吻九九”及制造方关于角色性格与互动的**未来设想**。这提供“如何从大装置走向可辨认角色”的研究问题，并非九九的官方设定、现有 AI 能力或受众效果。另可把[大唐不夜城《盛唐密盒》项目方采访](https://paper.people.com.cn/rmrb/pc/content/202506/16/content_30079510.html)作为“固定角色＋变化事件＋游客参与”的结构参照；它依赖真人即兴，不能直接映射到九九机械装置。两者目前都是**待完整审片的候选来源**，还不是项目已接受的视频证据。
