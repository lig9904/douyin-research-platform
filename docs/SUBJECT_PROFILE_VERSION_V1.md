# 通用主体档案版本：第一阶段代码边界

状态：030 版本已于 2026-09-24 发布测试服并完成隔离恢复与真实身份页面验收，见 [030 发布记录](releases/TEST_SERVER_030_20260924.md)。此后测试服已建立“九九”项目及一条待核准 IP 档案草稿；本页的“未创建”描述只适用于 030 发布当日，不是当前状态。档案到行动卡的精确引用已有后续版本，但正式创作、素材权利和业务效果仍需分别验收。

## 业务输入与输出

- 输入：项目中已有的研究主体；由项目 Owner/Admin 提供五类以内的短摘要（目标客群、可拍场景、叙事边界、禁用表达、当前事实），并填写受控来源引用、来源资料 SHA-256 和权利状态。系统不接收完整剧本、媒体或凭据。
- 输出：项目内版本号、生命周期、内容指纹和可读摘要。普通项目成员只能读取已核准版本的最小字段；项目管理者可查看草稿、历史和来源引用。
- 适用类型：IP 叙事、景区体验、活动转化和其他，不把“九九”写死在模型或页面中。

“已核准”表示负责人确认档案摘要及所填来源，**不等于素材使用许可**。权利状态为 `unknown`、`pending`、`restricted` 或 `prohibited` 时，后续创作、媒体利用及 L3 必须另行拒绝；即便为 `cleared`，仍需核验对应作品、素材和人工审核。来源 SHA-256 是操作者提交的指纹，当前系统不读取原件自动核真，不能把有指纹误当作已验证权利。

若事实来自多份原件，先在受控位置制作**固定来源清单**，逐份列出名称与原始字节 SHA-256；`source_reference` 指向该清单，`source_digest` 填该清单自身原始字节的 SHA-256。清单修订应另建版本，旧档案保留历史。不得将清单指纹误称为任一原件指纹，也不得填入无法复现生成过程的拼接指纹。负责人核准前需能取得原件/清单并复算；系统当前只验证 64 位格式，不替负责人验证正文或授权。

## 接口、权限与版本

- `get_subject_profiles(project_id, subject_id, include_history, pending_idempotency_key?)`：绑定 Windmill 终端用户身份及项目成员 ACL。非管理者即使传 `include_history=true`，也只返回当前已核准短摘要，不返回来源引用、来源摘要或审批人。仅项目 Owner/Admin 可用自己的幂等键核对这次草稿创建的精确回执；相同正文的旧版本不算本次成功。
- `mutate_subject_profile(project_id, subject_id, action, idempotency_key, ...)`：仅 Owner/Admin 可创建草稿、核准、标记替换或撤销；所有操作保留幂等审计。版本号由后端在锁定主体后自动分配，前端不能指定。
- 版本流程：新草稿可核准或撤销；已核准版本可标记替换或撤销。一个主体同时至多一个核准版本；换版需先保存新草稿，再标旧版为已替换，最后人工核准新版。三步不具备原子性，中间无可引用版本，不能把旧版自动复用。撤销后的草稿和已核准历史均保留审计信息，不可原地改写。
- 表 `research_subject_profile_version` 限定项目与主体组合外键、非空摘要、允许字段和摘要体积，数据库生成 SHA-256；核准后正文不可原地改写或删除。档案行保留审计历史，外键采用 `RESTRICT`，不能靠物理删除主体或项目级联抹除。

## 协作与验收边界

- 内容负责人负责确认事实、禁用表达与权利状态；研究员只读已核准摘要。“九九”测试项目已有一条草稿，但来源原件及素材权利尚未独立核实，不能仅因草稿存在就代负责人核准。
- 030 阶段验收覆盖隔离 PostgreSQL 迁移与 ACL/生命周期动态测试、Raw App 构建、跨项目与撤权拒读、草稿和来源不泄露、版本指纹稳定。后续精确引用与失效门禁见 [档案绑定契约](DECISION_PROFILE_BINDING_V1.md) 和 [下游消费边界](SUBJECT_PROFILE_DOWNSTREAM_CONTRACT_V1.md)。
- 页面在浏览器会话内按项目和主体保存待确认草稿的管理者身份、幂等键与意图 SHA-256，不保存摘要或来源正文。整页刷新后仅同一身份可读取这次操作的精确幂等回执；若回执未知，需按相同内容对账后再重试。浏览器不支持安全指纹或会话存储时，发请求前拒绝保存。030 已做测试服身份/页面验收，但“未知结果后的同正文重试”仍主要由测试覆盖。
- 2026-09-28 的页面修复让项目管理者在历史区展开草稿完整摘要、权利状态、来源引用及两个完整指纹；点击核准时也逐项显示同一内容。已在真实“九九”测试页面回读，草稿保持待核准，没有因 UI 修复自动改变生命周期或触发付费调用。
