# 项目多人协作与可选共享（测试服候选）

状态（2026-09-23）：代码、本地 PostgreSQL 测试与 CI 已通过。测试服务器已验证双库备份、完成 021–025 迁移及隔离恢复演练，并精确发布研究台 Raw App；远端应用版本从 39 升至 40。管理员浏览器已看到两个空白验收项目和“项目协作”成员名册。A/B/C 三个普通账号的独立浏览器权限矩阵、跨项目邀请/接受/撤销和含真实公开视频的共享证据仍待现场验收；不能把部署或管理员视图当成多人协作验收。

## 输入、输出与权限

- 输入：Windmill 服务端提供的 `WM_END_USER_EMAIL`、当前项目、已注册用户邮箱及所选角色。浏览器不能自报操作者身份。一个项目可有多名成员，一个成员可分别加入多个项目；加入 B 不会继承 A 的权限。
- 项目成员角色：负责人 `owner`、管理员 `admin`、研究员 `researcher`、分析员 `analyst`、只读成员 `viewer`。负责人可管理所有角色，管理员仅管理研究员、分析员和只读成员；最后一名负责人不可撤销或降级。成员的新增、改角色和撤权均追加有效期名册记录，保留历史，项目接口按最新生效记录判权。
- 协作页面输出：管理者可看到本项目成员、同组织可作为目标的项目、发出/收到的共享授权；普通成员只看到自己的角色与已获准的共享证据。权限不明、项目或组织停用时拒绝，而非回退到全局历史库。
- 审计：成员变动和共享状态变化写入 `project_access_event`；页面不返回审计库的原始记录、凭据或后台授权信息。

## 项目间授权

默认无共享。当前唯一可授予范围为 `public_video_evidence`：来源项目负责人/管理员向同组织的目标项目发出邀请，目标项目负责人/管理员接受后生效；最长 365 天，到期自动停止读取，双方均可撤销。目标项目普通成员只能查看已被来源项目纳入、尚未归档且当前标记为可用的视频的公开标题、平台、公开账号名和合并公开指标，以及来源项目名称。数据库函数在每次读取时核验目标成员、两个项目与组织状态、授权状态/有效期、来源项目纳入关系和视频可用状态。

本次**不共享**评论审核原文、转写、媒体对象、L3 结论、成本、原始 Provider 响应、项目私有设定或平台账号授权。共享内容在“项目协作”中单独展示，不将目标成员冒充为来源项目成员，也不修改原视频归属。未来扩展其它资料类型时应逐项增加归属与策略，不把 `public_video_evidence` 擅自扩展为“共享全部”。

## 接口与协作

`get_project_collaboration(db, project_id)` 是只读入口；`mutate_project_collaboration(db, project_id, action, ...)` 管理成员与共享状态。两者只接 Windmill 受控的研究库资源，页面不接收数据库密钥。Windmill 用户创建和登录仍由 Windmill 负责；本功能只管理业务项目成员，不创建账号或修改密码。Raw App 只能精确发布 `f/content_research/research_dashboard`，不能全工作区同步。

## 测试服验收

1. 先核实测试服备份、源提交和迁移 025 发布闸门；只在受控窗口执行迁移和 Raw App 精确发布，保持旧版运行路径可回退。
2. 使用真实普通账号 A 项目成员、B 项目成员、未加入者，以及 A/B 各一名管理者，独立浏览器会话验证：A 内多人可见，B 未授权时不可见 A 证据；A 发邀请但 B 未接受时仍不可见；B 接受后只看到允许的公开字段；任一方撤销、成员撤权、授权到期、项目/组织停用后刷新和直调接口均拒绝。
3. 验证管理员不能移除最后一名负责人，管理员不能提升自己或他人成负责人，不能跨组织共享；Job 输入/输出和页面不包含密码、Token、原始 Provider 响应、审核正文。真实账号密码由用户在 Windmill 页面自行设置，不进聊天、Git 或证据。
4. 隔离库单测和本地页面构建只证明候选实现；缺少上述真实浏览器证据时，不向普通项目成员宣称多项目共享已上线。
