# 自动转写的媒体审核绑定

状态：服务层与隔离数据库测试已实现；尚未部署真实转写任务及页面审核入口。

页面接入实现：视频详情增加音频列表、短时签名试听及保存审核。后端 `asr_media_review` 仅接受视频/资产/版本/动作/预览指纹；固定读取数据库与审核配置。列表不返回对象 key；试听先验证审核员与视频资产绑定，再核验私有对象，签名有效期 300 秒。页面成功提示以批准接口真实返回为准；音频未加载、播放报错、已撤销或已批准时不可再次保存。切换视频通过组件 key 重建状态，刷新列表/切换音频清除旧确认。

链接不持久化到研究数据库；但播放链接会作为 Windmill 作业结果返回，属于短期 bearer URL，应保持工作区作业结果访问受控，避免导出带链接的调试日志。未修改桶匿名权限。当前已做后端测试与前端构建，浏览器窗口不可用，未完成真实视觉、试听和保存交互验收，不能直接作为已上线能力。

迁移 017 增加 `asr_media_review`，记录音频资产、审核版本、资产指纹、HTTPS 投递源、审核人和有效状态。审核使用固定服务端审核员名单与 Windmill 已认证用户身份，禁止请求自行提供 actor 或 allowlist。资产指纹绑定视频归属、对象 key、内容摘要、大小及类型；临时签名查询不进入指纹。审核时验证预览指纹，已有撤销版本不会因重试批准而重新激活。

`LiveASRRequest` 必须指定已审核资产 ID、审核版本及内容摘要。执行前重新读取持久化审核，校验投递源和完整对象路径；缺失、撤销或错配会在 Provider 构造前拒绝。自动执行身份只读取 `f/content_research/automation_worker_identity`，不依赖浏览器登录或调用方姓名。人工审核身份与自动运行身份是不同责任。

任务键绑定视频、内容与模型版本，不绑定临时签名；链接更新后恢复同一提交并继续轮询。跨日恢复沿用原任务账期，显式更换账期仍视为输入冲突。费用未知保留 null/unknown，在已明确配置为不限金额时不因缺少报价阻止业务；已有请求护栏及明确金额限制仍生效。

本地测试使用隔离 PostgreSQL 和假 Provider，没有实际付费转写：覆盖缺失/撤销/错配审核、未授权身份、预览变化、签名轮换、原任务恢复、未知费用及零 Provider 构造拒绝。上线仍须完成审核预览与批准页面、固定 Secret 的 Worker 入口、服务器迁移、真实音频转写及页面展示验收。不得通过手工插入批准行替代真实业务审核。
