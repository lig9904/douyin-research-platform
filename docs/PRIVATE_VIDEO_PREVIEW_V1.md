# 研究台私有视频预览

## 输入与输出

视频详情顶部复用已有入库视频，不再显示固定占位预览。用户点击“加载视频 / 刷新链接”
才调用 `video_media_preview(video_id)`。无对象返回 `has_media=false`；单一有效对象返回
300 秒 HTTPS 播放链接；多对象歧义或校验失败明确失败，不随意选择版本。

## 权限与协作

- 使用与音频试听相同的服务端真实用户和审核人名单，授权在数据库资源和存储 Secret 读取之前。
- 数据库按视频与 kind=video 查询，复核绑定、内容寻址 key、摘要、大小和视频 MIME；
  只允许当前受控 bucket/storage_location 的对象。对象 HEAD 校验通过后才签名 GET。
- 不接收客户端 bucket、key、存储地址或身份。列表接口不携带链接，响应不额外暴露存储配置；
  签名 URL 本身是短时读取凭证，不写入持久化业务数据或主动打印到日志。
- 切换视频、重新加载或播放失败清除旧链接；异步响应带请求序号，过期响应不回填到新视频。
- 无采集、上传、转写、模型调用或审批写入；视频播放不等于音频或正文审核通过。

## 验收边界

本地前端构建、初始渲染零请求及既有转写展示回归已通过。
后端与音频审核定向测试 28 项通过，覆盖权限、对象绑定、空对象、存储错配、签名顺序和错误脱敏。
初始渲染检查是 SSR，不代表浏览器挂载、切换竞态或到期刷新已经通过。
只有在完成独立审查、CI 和单应用发布后，才可用真实页面验证加载、播放、切换与刷新。
本文件新增时尚未部署；不能把已有音频播放验收当作新视频播放器验收。

发布只针对 `f/content_research/research_dashboard` 完整 raw app，保留现有权限与其他后端。
不进行全工作区同步，不重启数据库、不改 MinIO 权限。新增后端 lock 与既有音频后端
使用相同依赖版本；部署时仍须核对实际依赖安装和应用 policy。
`wmill-lock.yaml` 使用官方 `generate-metadata rehash` 命令仅针对本应用离线刷新，
没有手写哈希、访问服务端或执行全工作区同步。
