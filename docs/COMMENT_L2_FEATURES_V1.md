# 评论证据 L2 确定性特征 V1

日期：2026-09-19

## 目标

把已经落入自有 Evidence Dataset 的评论与回复，转换为可复现、可版本化的 L2 特征快照。

本步骤：

- 不访问 TikHub
- 不调用 LLM
- 不做情绪、立场、受众画像或因果推断
- 不把评论样本冒充全部评论或全部受众
- 不把缺失值补成 0

规则版本：`comment-features-v1.0.0`。

## 快照字段

每个视频、规则版本和证据指纹对应一个不可变快照：

- 采样评论总数
- 根评论数
- 采样回复数
- 来源 observation 数
- 非空文本数
- 含问号文本数
- 点赞数已知样本数、合计、中位数
- 回复数已知样本数、合计、中位数
- 非空文本平均 Unicode code point 长度
- Provider 与 sample_reason 的聚合计数

原始评论 ID、文本、请求 ID、cursor、raw_ref 不进入快照 metadata。

## NULL 与 0

`like_known_count` 和 `reply_known_count` 单独记录覆盖度。

- 所有点赞数均缺失：`like_sum=NULL`、`like_median=NULL`
- 点赞数明确为 0：保留为 `0`
- 所有回复数均缺失：对应聚合为 `NULL`
- 回复数明确为 0：保留为 `0`

因此下游不会把“接口没给数据”误解释成“真实为零”。

## 幂等与版本

证据指纹由稳定排序后的评论证据及 observation keys 计算。相同证据重跑复用同一快照；新增原始响应 observation 或指标变化会生成新快照。

快照成功后，视频 `research_level` 最低提升到 L2。这里表示“已形成 L2 证据特征”，不表示内容质量高，也不表示已得出语义结论。

## 后续边界

V1 后续可以在明确的研究问题下增加：

- 分词后的高频词/短语
- 去模板化与垃圾文本规则
- 评论主题聚类
- 少量晋级样本的语义分析

但必须先有版本化规则、代表性说明和测试，不能直接把当前采样评论用于总体受众结论。
