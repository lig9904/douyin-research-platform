# 媒体理解的代码优先层

## V1

免费/本地代码先处理：
- ffprobe：时长、编码、分辨率、音轨
- FFmpeg：抽音频、按需抽帧、场景变化
- ASR：只对 L2/L3
- 文本规则：时长、句数、平均句长、开头/结尾时间窗

## V1.x 可选

如果真实 Case 证明需要：
- PaddleOCR：画面文字/字幕
- Silero VAD：长内容语音区间
- OCR 文本去重/时间合并

## 强模型最后

只有在代码层无法解释时才把少量关键帧送多模态模型，例如：
- 纯视觉笑点
- 镜头信息与台词矛盾
- 角色动作导致的反转
- 强视觉奇观

不要默认把整条视频逐帧送多模态模型。
