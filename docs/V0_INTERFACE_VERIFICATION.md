# V0 接口验证清单

目标：在写业务逻辑前，用真实响应确认接口、字段、成本和限制。

## 必测能力

- [ ] 热点/趋势榜
- [ ] 视频总榜
- [ ] 低粉爆款
- [ ] 高完播
- [ ] 高涨粉
- [ ] 高点赞
- [ ] 视频搜索
- [ ] 账号搜索
- [ ] 账号作品：最新
- [ ] 账号作品：最热
- [ ] 视频详情
- [ ] 评论
- [ ] 评论回复
- [ ] 数据分页
- [ ] 限流行为
- [ ] 错误返回
- [ ] 删除/私密视频表现
- [ ] 价格/计费查询

## 每个接口记录

- endpoint / SDK method
- 请求参数
- 必需权限/套餐
- 原始响应样例
- 稳定唯一 ID
- 可用指标
- 缺失指标
- 分页方式
- 单次返回数量
- 限流
- 错误码
- 单次/阶梯成本
- 是否适合 L0/L1/L2/L3

## 验收

完成验证后，才能冻结：

- Provider Interface
- 数据库字段映射
- 采集频率
- L0/L1 漏斗规则
- API 日预算
