# 账号相似度 L2 V1

日期：2026-09-20

## 目标与输入

本能力只比较本库已经保存的同平台账号资料，用于在研究台详情中给出小规模、可解释的候选对标账号。它不调用 TikHub、ASR、embedding 或 LLM，也不读取密钥、原始评论、视频正文或账号 bio 文本。

输入取自既有事实表：

- `source_account`：平台、账号类型、认证类型；
- `account_tag`：`content_domain` 标签；
- `account_metric_snapshot` 的最新快照：粉丝数、作品数。

这不是平台原生“相似达人”接口的替代，也不表示受众、内容语义或商业价值相似。

## 规则与输出

规则版本：`account-similarity-v1.0.0`。总权重为 100：内容领域 Jaccard 45、账号类型精确匹配 15、认证类型精确匹配 10、粉丝数量级接近度 20、作品数量级接近度 10。

数量级接近度用 `log10(count + 1)` 的距离线性衰减；相差三个数量级或以上得 0。缺失字段不补成 0，且不进入可比较权重。候选必须至少有 45 权重的双方已知字段，返回：

- `similarity_score`：按双方已知字段归一化后的 0–100 分；
- `evidence_coverage`：实际可比较权重，防止稀疏资料被误读为完整比较；
- `raw_score`、各字段分量、匹配的领域与字段，供页面解释。

只比较同一 `platform`，排除自身；结果按分数、覆盖度、原始分和账号 ID 稳定排序，默认最多 5 条。因此相同数据库快照重复运行得到相同输出。

## 边界与验收

本模块为纯 Python 标准库计算，无外部依赖和持久化副作用。单元测试覆盖输入顺序无关、自身/跨平台排除、缺失值不零填充、资料覆盖度下限、数量级评分、限制条数和异常负数显式失败。

页面仅展示候选和其已知证据；没有候选不等于“没有相似账号”，只表示当前本库资料不足或未达到上述比较阈值。后续若接入平台原生相似达人或 embedding，必须另起版本并保留来源、模型版本和独立验收。
