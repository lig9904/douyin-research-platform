# TikHub 可选能力分层

日期：2026-09-19

## 目的

把 TikHub 已经提供、但不应该全部默认开启的能力按用途分层，避免重复开发，也避免因为“接口有”就高频调用。

## A. V1 推荐进入核心链路

### 1. Billboard / Creator Center：发现层

推荐作为 L0 信号源：

- 低粉爆款 / 高完播 / 高涨粉 / 高点赞
- 热点总榜 / 上升热点
- 同城热点
- 热门账号
- Creator Center 热门视频
- Creator Center 热门话题
- Creator Center 创作热点

Creator Center 目前直接支持旅行、剧情、二次元、文化教育、创意等分类，并支持 24h / 7d / 30d 以及播放、点赞、评论、热度等排序。

同城热点可使用 city_code，适合秦皇岛本地信号补充。

原则：这些只是发现源，不直接等同于“值得深研”。

### 2. Index：结构化 Intelligence 层

Index 不应只被理解为“视频搜索”。

可直接提供：

- 多关键词热度趋势
- 多关键词指数解读
- 关联词
- 关键词人群画像
- 垂类热门话题
- 垂类热门关键词
- 内容发布趋势
- 创作时长分布
- 创作者画像
- 消费者画像
- 互动趋势
- 消费趋势
- 推荐/趋势报告
- 热点详情分析

这意味着以下任务默认先用结构化接口 + SQL/代码，不调用 LLM：

- 哪些关键词正在变热
- 哪个垂类消费在增长
- 某垂类主流时长分布
- 某关键词关联什么搜索/内容词
- 某垂类观众年龄/性别/地域/兴趣结构
- 本周某垂类热门创作话题
- 关键词 A/B/C 的趋势对比

LLM 只负责解释复杂现象，不负责重算平台已有结构化统计。

## B. V1 可选 L2 enrichment

### Billboard 账号/观众扩展

TikHub Billboard 目录当前还包括：

- 作品点赞观众画像（仅热门榜）
- 账号粉丝数据趋势
- 账号作品分析（上周）
- 粉丝画像
- 粉丝兴趣作者
- 粉丝近 3 天兴趣话题
- 粉丝近 3 天搜索词

这些能力非常有价值，但不应默认对所有账号调用。

建议：
- 只在重点账号 / 重点热门作品进入 L2 后按需调用
- V0 实测确认是否支持任意 sec_uid / aweme_id
- 实测价格、覆盖率、返回字段、空数据条件
- 若结构化返回已够用，不再调用 LLM 做“用户画像猜测”

### 作品点赞观众画像

仅限热门榜作品，应视为“榜内样本额外证据”，不能假设普通视频都可用。

## C. Creator API：额外热点源

Douyin Creator API 当前有：

- Creator 热门视频榜
- Creator 热门话题榜
- Creator 热点榜
- 热门道具
- 热门音乐
- 热门挑战
- 热点/话题相关视频

这些接口只需 TikHub Bearer Token（按当前文档），不要求我们自己的创作者 Cookie。

V1 可以将其中最有用的三类加入低频 discovery：

1. 热门视频榜
2. 热门话题榜
3. 热点榜 / 同城热点

道具、音乐、挑战先不默认开启，除非后续证明对九九研究价值高。

## D. 不进入 V1 外部研究主链：Creator V2

Creator V2 是“自己的创作者账号后台数据”，需要有效 Douyin Creator Platform Cookie。

已确认可取：

- 单条作品观看留存曲线
- 点赞发生时间曲线
- 跳出曲线
- 流量来源
- 实际搜索关键词
- 作品观众画像
- 弹幕时间分布
- 投稿作品列表
- 投稿表现
- 垂类标签

这是未来 V2 “自有账号结果回流”的关键能力，而不是 V1 外部对标采集能力。

绝不使用别人的 Cookie，也不尝试绕过登录。

## E. 不默认使用

### Xingtu

只有普通 Search/Billboard/Index/App V3 无法满足明确研究需求时才启用。

原因：
- 部分 endpoint 价格明显更高
- V1 的低粉账号发现、作品表现、热点研究已有更便宜接口

### 全量粉丝列表 / 关注列表

不是 V1 目标，数据量大且价值有限。

### 全量评论

只用于极少数深研样本。

### 最高画质视频

V1 无 NAS、无生产资产需求，默认关闭。

## V0 新增验证项

1. 作品点赞观众画像是否严格只对 Billboard 热榜作品有效。
2. fan portrait / fan interests 对任意重点账号的覆盖率。
3. account fan trends 的字段语义与标题是否一致。
4. account work analysis 的字段粒度。
5. Creator Center 热门视频/话题/热点接口真实价格和稳定性。
6. Index 各结构化 intelligence endpoint 的价格、可用日期限制和空数据条件。
7. Index category/tag ID 是否可动态获取并稳定映射。
8. Index 结构化结果是否允许直接历史化比较。
