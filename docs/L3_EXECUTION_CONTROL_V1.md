# L3 付费模型执行控制层 V1

日期：2026-09-19

## 结论

本层为 L3 模型生成提供供应商无关的执行控制，但不假定任何模型中继的 URL、鉴权、模型名或请求格式，也不读取 Secret、不包含具体模型客户端。

单次运行严格限制为：

- 最多 1 次模型调用
- 自动重试 0 次
- PostgreSQL 单并发锁
- 已知 LLM 估算成本预占
- 稳定 task key
- 调用状态不确定时禁止再次调用

## 零调用预览

`execute=false` 时只返回：

- 最大外部调用数 1
- 最大 LLM 调用数 1
- 估算总成本；未知保持 NULL
- 币种
- 是否具备执行所需的已知估算
- 当前实际调用数 0

预览不访问数据库、不组装研究证据、不构造 Provider、不读取 Secret、不写任务状态。

## 正式执行闸门

正式执行必须同时满足：

1. `execute=true`
2. `confirmation=RUN_L3_MODEL_PAID`
3. Schema 固定为 `l3-research-v1.0.0`
4. 视频已经达到 L2
5. 视频已由确定性 L2→L3 Gate 选中
6. LLM 估算成本已知且非负
7. 当天已配置 `provider / windmill_manual_l3` 预算
8. 请求币种与预算币种一致
9. Provider 名称匹配、定价版本非空且 `max_retries=0`
10. Provider 执行契约经过核验且标记为 production ready
11. 证据规范 JSON 的指纹重算一致，最新持久化人工隐私复核与证据版本一致
12. 单并发锁获取成功

数据库前置检查通过后才组装证据；证据成功后才构造 Provider。任何外部调用前，系统会原子预占一次请求额度和 LLM 估算成本。

Flow 或执行代码不得自动创建、扩大或切换预算币种。

## 一次执行与故障语义

预算预占和 `l3_execution_job(status=running, attempt_count=1)` 在调用前持久化。

- 调用成功并通过版本、成本及隐私结果校验：写入 L3 结果与逐任务成本，任务变为 `completed`。
- Provider 返回的证据 modalities 必须与输入集合完全一致，不能声明未提供的证据。
- 已知实际 LLM 成本超过预占时，不写分析结果；任务以 `provider_cost_exceeded_reservation` 失败，并把实际费用完整记入逐任务成本和当天预算。
- 调用抛出异常：任务变为 `failed`，不自动退款、不重试。
- 进程在调用附近中断且无法确认是否已计费：后续相同 task key 返回 `reconciliation_required`，禁止猜测性重跑。
- 已完成或失败的 task key 重放：只返回已有聚合状态，不重新组装证据、不读取 Secret、不调用模型。
- task key 对应的输入、模型或版本变化：拒绝复用。

如果结果已成功写入但任务状态更新中断，协调器可通过 `research_task_cost` 自动恢复终态，不再次调用模型。

## 成本语义

L3 模型执行的分类约定：

- `api_cost=0`：本任务没有独立的数据 API 调用。
- `asr_cost=0`：本任务没有新增 ASR 调用。
- `llm_cost`：模型生成的实际或估算费用。
- 模型调用失败且实际费用无法确认时，`llm_cost=NULL`，因此 `total_cost=NULL`。
- 预算采用保守预占，不根据异常文本推断供应商未收费，也不自动退款。
- 已知实际费用高于预占时，预算会追加差额，即使追加后超过上限也保留真实发生额；该情况失败关闭，必须人工对账后才能调整后续预算。

## 数据与隐私边界

`l3_execution_job` 保存模型/Prompt/Schema/证据/隐私复核/定价版本、输入指纹、Provider 契约指纹、证据 modalities、预算日期、估算成本和脱敏状态，不保存证据包或模型原始响应。

证据包只在内存中交给 Provider，请求对象的调试表示也隐藏证据内容。Provider 返回结果必须：

- 与请求中的模型、Prompt、Schema 和输入指纹完全一致
- 已完成明确的隐私复核
- 通过 L3 结构化结果契约
- 不把未经复核的原始评论、转写、昵称、平台 ID 或请求标识直接写入结果

外部返回只包含状态、当次调用数、尝试次数、是否有成本记录和内部脱敏错误码。

## 尚未完成

仍需在核验实际模型服务契约后实现具体适配器：

- base URL 与鉴权方式
- 模型/能力标识
- JSON Schema 或结构化输出方式
- token 与成本字段
- 超时语义
- 内容安全和隐私复核步骤
- 上游是否存在隐式重试

具体适配器接入前，不得使用正式密钥发起真实模型调用。本仓库仍不附带 schedule。
