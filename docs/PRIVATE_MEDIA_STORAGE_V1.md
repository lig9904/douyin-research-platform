# 私有 S3 媒体存储

## 当前边界

已实现存储适配器、媒体元数据、缓存详情到视频/音频对象的服务层，以及独立真实存储验收脚本。媒体服务层已在隔离 PostgreSQL 和模拟下载/S3 上验证，并完成本机真实 ffmpeg 合成音频转换；尚未部署研究台媒体任务入口、播放页或云端 ASR 自动链路。不得把这些测试标记为服务器真实视频全链路完成。

`S3MediaStorageConfig` 显式接收 endpoint、bucket、region、access_key_id、secret_access_key、force_path_style、use_ssl，以及可选的 HTTPS public_endpoint。适配器本身不读取环境变量或 Windmill Secret，后续入口负责从受控配置装配。凭据不写源码、Git、日志或验收报告。

- 上传端点使用应用服务器可访问的内网 S3 origin。
- 公网 HTTPS origin 专门用于预签名下载。签名时就使用外网域名和端口，不能在签名完成后替换域名。
- 桶保持私有。上传不设置 ACL，不修改桶权限、不创建密钥、不创建桶。
- 对象键按 SHA-256 内容寻址；HEAD 检查摘要 metadata、大小和 ContentType，已存在且一致时复用；403 不当作不存在。同一哈希不自动重写已有 MIME 类型；类型主体大小写不敏感，参数值仍严格核对。
- SDK 使用 S3v4，连接超时 5 秒、读取超时 30 秒，总尝试次数 1。
- 签名有效期 60–3600 秒，默认 900 秒。签名链接属于临时凭据，不记录完整 URL。
- Nginx 保留 `$http_host`（包括非默认端口），不重写对象路径；S3 和管理控制台不共用此反代入口。

## 小规模真实验收

在安装项目依赖后运行：

```sh
PYTHONPATH=src .venv/bin/python scripts/s3_media_smoke.py \
  --endpoint https://YOUR-S3-HOST:6443 \
  --public-endpoint https://YOUR-S3-HOST:6443 \
  --bucket YOUR-PRIVATE-BUCKET
```

Access Key 和 Secret Key 通过终端无回显提示输入，不作为命令行参数、不保存。应用服务器验收时，将 endpoint 改为内网地址，public-endpoint 保持公网地址。

脚本生成 1644 字节、0.1 秒静音 WAV，验证上传、重复调用复用、5 分钟 S3v4 签名下载、下载字节和 SHA-256 一致、匿名 GET 403、篡改签名 GET 403。成功时保留一个极小验收对象，并打印其非敏感 key/size/hash；不删除已有对象，不调用任何付费接口。

失败报告只保留阶段和白名单错误码，不输出服务商异常正文或签名 URL。`InvalidAccessKeyId` 表示服务端不认可实际提交的 Access Key，需要核对原始文本与目标 MinIO 实例；不要直接放宽桶权限，也不要自动尝试多种猜测密钥。

实际通过上述验收后，才继续部署应用配置及媒体下载任务。静音 WAV 验收不证明真实视频提取或 ASR 转写已完成。

## 视频与音频服务层

- 迁移 `016_media_asset.sql` 保存对象 key、内容摘要、大小、类型、来源响应 ID 和父媒体引用；不存签名 URL。对象内容可以跨视频复用，但资产记录始终绑定自身 video_id，音频父资产不能来自另一视频。
- `MediaIngestionService` 输入已入库的抖音 video_id，读取其已保存的 TikHub `data.aweme_details`，精确匹配平台视频 ID。下载源缺失或失效时返回失败，不偷偷发起付费详情刷新。
- Worker 的可信配置提供私有存储位置、桶、下载 CDN 白名单、临时目录、执行身份及 ffmpeg 路径；这些参数不能直接作为公共表单自填权限来源。当前配置默认单文件处理上限 2 GiB，是可配置的 Worker 资源保护，不是 Nginx 上传限制或金额上限。
- 视频下载、上传和音频转换都核对内容摘要及大小。音频固定为单声道、16 kHz、16-bit PCM WAV。ffmpeg 使用参数列表、关闭网络协议与标准输入；错误不持久化 stderr 或原始 URL。
- 每个视频使用数据库会话锁。完整视频/音频资产存在时，确认 S3 元数据仍匹配后直接复用；缺失或拒绝读取不能冒充复用成功。
- 音频提取失败而视频已存储时，重跑从私有 S3 恢复视频，逐字节核对摘要和大小，不再次调用 CDN 下载或收费详情接口。
- 处理过程写入 `pipeline_run` / `pipeline_run_item`；失败码按来源查询、下载、上传、提取、元数据阶段区分。Worker 异常退出后，下个持锁执行将遗留 running 标记为中断，再安全继续。普通失败会清理本次临时文件，不删除已有对象。
- 临时目录必须是预先配置的绝对路径，测试服应确认其实际存储位于 500G 盘；当前服务器 Worker 未发现 ffmpeg，部署前需提供可重复安装的运行时，而非仅在一次性容器手工安装后宣称完成。

下一阶段仍须验证：服务器内网 MinIO 上传、真实视频提取、短期签名播放、ASR 输入审核持久化、进程强制退出后的临时目录运维清理。元数据记录本身不构成 ASR 或 L3 的隐私审核批准。
