# 平台品牌图标 V1

研究台不再用字符近似平台标识。前端只内置当前界面用到的六个品牌 SVG path，不在运行时请求第三方 CDN，也不把整个图标包打入 App。

图标路径和品牌色取自 `simple-icons@16.31.0`。Simple Icons 代码仓库采用 CC0-1.0；这不代表各品牌标识本身进入公有领域，也不授予任何商标权。实际使用仍须遵守抖音/TikTok、快手、微信、小红书、哔哩哔哩和微博各自的品牌规范。

- 抖音：TikTok 品牌形状，`#000000`
- 快手：Kuaishou，`#FF4906`
- 微信视频号：当前使用真实 WeChat 父品牌标识，`#07C160`
- 小红书：Xiaohongshu，`#FF2442`
- B站：Bilibili，`#00A1D6`
- 微博：Sina Weibo，`#E6162D`

Simple Icons 当前没有单独的 Douyin 或 WeChat Channels 条目：抖音使用同一乐符品牌形状，视频号使用微信父品牌图标并在界面保留“视频号”文字，避免将自制图形误称为官方图标。

当前图标覆盖平台筛选、首页卡片、视频/账号/热点列表及详情、全局搜索和成本页平台列。

无障碍语义由外层 `role="img"` 与中文 `aria-label` 提供，内部 SVG 只负责绘制并对读屏隐藏，避免重复朗读。
