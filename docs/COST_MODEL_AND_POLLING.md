## 原估算更正

旧版误将50条批量详情计为USD0.001/批，正确基础价为USD0.050/批。
1000视频20批应为USD1/轮，每天6轮为USD6；原USD0.02/轮和USD0.12/日撤回。
此前把所有业务请求统一乘USD0.001的日/月估算也撤回：视频搜索为USD0.010/页，
批量资料等另有单价，免费费用查询不应按付费基础价累计。

## 新估算方法

先确定需要的字段及新鲜度，再计算去重后需要外呼的ID/页面数。

- 详情：单条USD0.001，10批USD0.010，50批USD0.050；基础价下尾批选单条/10批，避免空槽。
- 统计：小请求最多2个ID/USD0.001，50批USD0.025；只做增长监测时优先验证统计字段。
- 账号主页与单账号资料：USD0.001/请求；50人批资料USD0.150，不是更便宜的默认方案。
- 评论按讨论串和页面数累计；ASR按音频时长；模型按具体版本/服务档/实际token分类累计。
- 阶梯折扣只对符合资格的endpoint按边际请求档生效；本地结果复用无需新付费调用。

## 建议频率（待自动任务实现与验收）

| 业务 | 建议起步频率 |
| --- | --- |
| 核心发现/榜单 | 30min，优先首1页；按新增率决定是否加频/加页 |
| Creator垂类/非核心信号 | 1–2h |
| 活跃高分视频统计 | 0–6h年龄每1h；6–24h每2–3h；1–3d每6–12h；3–7d每天；之后停活跃跟踪 |
| 账号主页 | A类2h/B类6h/C类24h，遇已知ID停止增量翻页 |
| 账号基本资料 | 新增/缺字段/过期时，通常每日足够 |
| Index日趋势/周分布 | 随上游数据周期，日更/周更；避免高频重复查询 |
| 评论、ASR、L3 | 案例晋级/人工研究问题触发，按内容和版本复用 |
| 价表/账单 | 每日一次及新启用endpoint前；按供应商时区对账 |

该频率只刷新需要的字段，不全库每次重拉完整详情。当前代码的请求指纹缓存还不能
替代逐视频字段新鲜度筛选；该能力需先实现再启用自动轮询。

## 金额与记账

用户当前不设置金额硬上限。保留业务任务范围、分页终止、供应商限速和精确计费，
不恢复原80%/95%/100%金额熔断。当前daily_budget为预占，实际结算以供应商账单为准。
失败/超时未知费用不伪记免费。USD和CNY分列，免费抵扣、折扣、税费/汇率分别记录。

新的明确工作量示例为USD1.287/日、USD38.61/30日，
详见业务策略的逐项算式；ASR、LLM、流量、存储和服务器另列，不能当作已发生账单。
