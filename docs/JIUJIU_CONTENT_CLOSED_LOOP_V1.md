# IP 内容研究闭环：公开验收边界

本文件沿用既有链接，仅记录通用验收边界。试点的公开定位见[IP 账号公开边界](IP_ACCOUNT_PUBLIC_BOUNDARY.md)，具体创意与角色资料不在公开仓库保存。

输入包括经授权的项目目标、公开案例及来源、内容审核结论和自有账号发布后的同口径结果。系统按项目隔离保存原始依据、合并指标、研究判断、行动版本和费用；输出必须区分已证实事实、推断与未知，并能回到来源和观察窗。

协作由项目负责人确认目标和素材权利，研究员核对可比性与反例，制作团队在受控渠道形成实际可播放内容，运营在发布后提供后台汇总。项目成员权限和跨项目授权分别校验；撤权后不能再读取项目私有依据。

验收分层进行：技术链路需真实运行和回读；内容方向需获授权的设定、可比案例与观众反馈；效果需真实发布后的自有数据。任何一层缺失都保持“待验证”，不以外部热视频、机器稿或单次测试代替业务结论。通用对象与权限模型见[通用内容研究闭环](CONTENT_RESEARCH_CLOSED_LOOP_V1.md)。
