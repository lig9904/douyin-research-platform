## 能迁移的是“角色功能测试”，不是迪士尼配方

首次出场故事把一个**可被记住的行动方式**放进了问题：玲娜贝儿善于观察并帮助迷路者；后续《Lunchbox Mystery》换了问题和群体情境，但继续让同一角色拿放大镜查线索。由此可以提出可证伪的九九研究问题：在 IP 负责人签认当前角色设定后，九九是否也有一种**现实可呈现、可在不同事件中重复使用、会带来后果**的行动方式？旧 PoC 输入中的“好奇、好胜、有担当、守护”仅是待核对版本的候选性格，不作为当前正式设定。这只是结构推论，不是让九九学侦探、照搬解谜道具或擅自确认新能力。

与已采的国内有限样本合看，初步创作判断分三层：

1. **识别层：**名字、形象和一个可复述的动作须同时出现；只有机甲规模和景点介绍，容易让观众只记住设施。横店“下班打车”与宋城“花盆人上班”能证明普通处境可让奇特角色进入日常语义，但不能证明九九应照搬笑点。
2. **行动层：**每条内容写清“谁遇到变化—九九如何基于动机作选择—观众看到什么后果”。长安雅集的问答证明参与结构存在，夔牛机械兽则提供“仅展示设施”的对照；两者均不能替九九提供已批准的行为或现场能力。横店“姑姑收到惊喜”成片缺关键送花/对话，已下调为弱线索，不可用高赞替代缺失的因果。
3. **延续层：**若角色功能成立，下一条换情境、推进关系或暴露缺点带来的后果，而不是只改标题编号。王大人 410–415 集仅证明稳定角色包装可连续供给，**没有**证明同一观众追更或角色弧积累；迪士尼官方两片只为“角色功能跨作品复用”提供更明确的结构参照。

## 对九九业务的可执行输出与门槛

- 内容团队可先把每条构想填成五格：**本条问题、九九想要什么、实际选择、可见后果、下一条能怎样变化**。填不出第四格的，只算角色展示或气氛片，不归入“人物故事”栏目。此为创作分类规则，仍允许非剧情的演出记录/幕后内容存在。
- 制作团队用已获许可的现有素材或纸面分镜并排做“实体/形象先行”和“动机—选择—后果先行”两版；版本必须匹配画质与结尾，盲看者只评价九九是否被理解。内部试验协议和未决 IP/现场输入见本机保密的九九概念实验卡，不能把该文件或内部剧本直接上传到公域。
- IP 负责人必须先确定线上角色与旧演出中真九九/机甲九九/凌墨的关系，以及动作、声音、形象与能力的权利边界；没有签认版本，**不**把外部模式改写为正式九九剧集。
- 官方九九账号建立后，用自有后台同口径 48 小时与 7 日非个人汇总观察触达、观看留存和关注等实际可得指标；它们**不能直接测量**角色记忆或后续观看意愿。记忆与意愿应依靠目标人群盲看后的直接提问、经同意的访谈/反馈编码，并记录样本数与问法。若后台无法核出年龄分层，只能报告总体结果，不冒充 18–35 岁结论。第三方公开视频计数与供应商异常“零播放”不参与效果归因。

本卡可支持**内部方向讨论**：“让九九有可持续、符合最终签认人设的行为，而不是只当演出装置”；尚不能支持“哪类内容一定增长最快、应拍几秒、应投入多少制作费”的决策。下一步仍需完整可比正反案例、当前 IP/现场权利核对，以及两版概念片的真实目标观众反馈。
